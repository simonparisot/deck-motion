deck-motion

Presentations that behave like slides, and look like motion design.

A skill for Claude Code. No dependencies, no build, one file to open. You drive it from the keyboard during a talk, or let it run on its own on a lobby screen.

Open the demo deck Get the skill

What the demo is

A full one-hour opening plenary for the annual seminar of a fintech that does not exist. Twenty-six screens, six chapters, an animated map of France, a Sankey diagram of the underwriting funnel, speaker notes, a contents panel and a timer.

It was generated from one preparation note, the kind anyone writes before a talk: the numbers, the running order, what the speaker wants the room to remember. Read the note, then open the deck. That is the whole point of the skill.

The deck and the note are in French. The skill itself is in English.

Driving it

  • → moves one step, then one screen
  • N speaker notes · S contents · F full screen
  • B blacks the screen out, so the room looks at you
  • ?static=1 drops every animation and shows the final states

Install

git clone https://github.com/simonparisot/deck-motion.git \
